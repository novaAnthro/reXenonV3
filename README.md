# Xenon V3

Lua/Luau-скрипт с пользовательским интерфейсом и набором инструментов для **Your Bizarre Adventure (Roblox)**.

> Проект зависит от внутренней структуры игры, API Roblox и возможностей конкретного исполнителя скриптов. Совместимость после обновлений игры не гарантируется.

## Содержимое репозитория

| Файл | Назначение |
|---|---|
| [`XenonV3.lua`](XenonV3.lua) | Основной скрипт |
| [`libXenonV3GUI.lua`](libXenonV3GUI.lua) | Библиотека графического интерфейса |
| [`docs/LUA_API.md`](docs/LUA_API.md) | Документация внутреннего Lua API |

## Основные разделы

- **Player** — параметры персонажа, передвижение и вспомогательные функции.
- **Autofarms** — автоматизация сбора предметов, получения стендов и выполнения отдельных игровых задач.
- **Teleports** — перемещение к сохранённым точкам, NPC и объектам.
- **Misc** — дополнительные настройки, анимации, предметы, горячие клавиши и инструменты.
- **SBR** — вспомогательные функции для Steel Ball Run.

Набор пунктов интерфейса может зависеть от режима игры и загруженных данных.

## Запуск и зависимости

Основной скрипт загружает GUI-библиотеку из этого репозитория:

```lua
local Library = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/wut780/xenonV3_extr/main/libXenonV3GUI.lua"
))()
```

Конфигурация по умолчанию по-прежнему загружается из Pastebin:

```text
https://pastebin.com/raw/XXkRbtKN
```

Содержимое этой пасты не удалось получить во время подготовки документации: запросы к Pastebin были недоступны. Поэтому ссылка оставлена без подмены неизвестными данными. При отсутствии локального JSON-файла скрипт использует эту удалённую конфигурацию.

Настройки и сохранённые данные используют файл конфигурации по умолчанию:

```text
XenonV3/XenonConfig.json
```

Также скрипт создаёт каталог журналов `XenonV3/Logs`.

## Webhook-уведомления

Три ранее встроенных адреса Discord Webhook удалены из основного скрипта. Уведомления используют только пользовательское значение `Webhook` из конфигурации. Не добавляйте токены вебхуков непосредственно в публичный исходный код: URL вебхука предоставляет возможность отправлять сообщения от имени соответствующего webhook.

## Требования и ограничения

- Roblox и актуальная версия Your Bizarre Adventure.
- Исполнитель скриптов с поддержкой используемых функций, включая `loadstring`, `game:HttpGet`, файловые операции и HTTP-запросы.
- Доступ к удалённым ресурсам, указанным в зависимостях.
- Часть функций использует внутренние объекты и RemoteEvent/RemoteFunction игры; после обновлений они могут перестать работать.

## Безопасность

Проверяйте загружаемый Lua-код и внешние зависимости перед запуском. Не запускайте неизвестные скрипты в аккаунте с ценными данными. Не публикуйте конфиги, содержащие токены, webhook URL или другие секреты.
